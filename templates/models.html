Models & API key

Test other models

Paste your own OpenRouter API key and add any model id to make the whole lab (Attack · Defense Lab · Benchmark · Use Cases) run live against those models. Everything here is stored only in this browser (localStorage) and sent to the local lab server solely to make the call — never logged or saved to disk.

OpenRouter API key

Without a key the lab uses the server's key (if configured) or REPLAY mode. Get a key at openrouter.ai/keys.

Custom models

Add any OpenRouter model id — it appears in every model picker. Examples: anthropic/claude-3.7-sonnet, deepseek/deepseek-v4.1-flash, x-ai/grok-4-fast, google/gemini-2.5-pro.
Built-in models are always available; these are added on top.
